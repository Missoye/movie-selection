# 🎬 Movie Catalog

An interactive web application to browse movies by genre, save your favorites, and export your selections.

## Features

- 📽️ Browse movies across 8 different genres
- ❤️ Select multiple movies to save as favorites
- 💾 Persistent storage (favorites saved in browser)
- 📋 Copy favorites to clipboard
- 💾 Download favorites as JSON or Text file
- 📱 Fully responsive design
- 🎨 Modern, interactive UI

## Genres Included

- Action
- Comedy
- Drama
- Horror
- Romance
- Sci-Fi
- Thriller
- Animation

## How to Use

1. Open `index.html` in your web browser
2. Select a genre from the left sidebar
3. Check the checkbox next to any movie to add it to favorites
4. Visit the "Favorites" tab to see all selected movies
5. Use the export buttons to copy or download your favorites

## Export Options

- **Copy to Clipboard** - Quick copy to paste anywhere
- **Download JSON** - Export with metadata and timestamps
- **Download Text** - Formatted text file organized by genre

## Technical Stack

- HTML5
- CSS3
- Vanilla JavaScript
- localStorage API

## Local Storage

Your favorites are automatically saved in your browser's local storage, so they persist even after closing the browser.
